# Observatorio Energético de Colombia

## English

### Overview
This repository contains the **Observatorio Energético de Colombia** project, including data processing assets and an Astro-based interactive presentation site.

### Repository structure
- `Ingestion/`, `Bronze_Load/`, `Silver_Load/`, `GOLD LOAD/`, `Gold_Analytics/`: data pipeline and analytics artifacts.
- `EDA/`: exploratory data analysis material.
- `DDL's/`: data definition scripts.
- `Automation/`: automation-related assets.
- `observatorio-energetico-astro/observatorio-energetico-astro/`: Astro web project.

### Run the Astro site
```bash
cd observatorio-energetico-astro/observatorio-energetico-astro
npm install
npm run dev
```

### Build the Astro site
```bash
cd observatorio-energetico-astro/observatorio-energetico-astro
npm run build
npm run preview
```
